# 宠物潮流穿搭 × 情绪头像

把一张真实宠物照片变成一张有性格的 **1:1 方形潮流头像**：宠物仍然是它自己，只是穿上合身的美式街头服，在一个有明确情绪和生活感的场景里被朋友随手拍到。

![宠物潮流情绪头像示意](https://img.shields.io/badge/Codex-Skill-111827?style=flat-square)
![输出比例](https://img.shields.io/badge/Output-1%3A1-0F766E?style=flat-square)

## 能做什么

- 保留宠物的物种、毛色、花纹、脸型、眼睛、耳朵、尾巴、体型与原始神态，让它一眼仍然可认。
- 加入真实可想象的宠物定制穿搭：连帽卫衣、varsity 夹克、牛仔外套、工装马甲、棒球帽、方巾等。
- 把宠物安排进一件清楚的小事：打游戏、看电视、听音乐、等朋友、摸鱼办公、花园茶会等。
- 统一成 1990s–2000s 美式家庭相册的直闪质感：浓青蓝/蓝绿色、暖红棕/琥珀色、硬闪阴影、彩色颗粒与略微失真的抓拍感。
- 生成过程保护动物结构：不接人类身体、手指或四肢；四足宠物保持自然四肢，鸟类保持自然翅膀和双足。

## 适用场景

- 宠物社交媒体头像
- 宠物穿搭照与表情包素材
- 想把宠物做得有趣、搞怪、酷或可爱，但不希望变成卡通或玩偶
- 需要连续生成多张不同地点、动作与服装的宠物写真

## 不适用

- 把真实宠物改成卡通、3D 角色或人类
- 商业品牌广告、可识别商标或带文字的海报
- 只想做干净棚拍/电商白底图

## 安装

将仓库克隆到 Codex 的本地 Skills 目录：

```bash
git clone https://github.com/luji12/luji-pet-streetwear-mood-avatar.git \
  ~/.codex/skills/pet-streetwear-mood-avatar
```

然后在 Codex 中使用 `pet-streetwear-mood-avatar`，上传宠物照片并说明想要的情绪、服装、场景或动作。

## 使用示例

```text
使用 pet-streetwear-mood-avatar，把我上传的宠物做成 1:1 头像。
它要倒戴棒球帽、穿深色 varsity 夹克，坐在傍晚篮球场边，
旁边放一个无品牌篮球；保留它原本的脸、毛色、耳朵和自然肢体。
```

```text
使用 pet-streetwear-mood-avatar，做一张可爱女性装扮。
给它粉色针织小开衫、耳边蝴蝶结和小花胸针，
放在薄荷绿花园茶会场景；画面要保留真实宠物质感，不能卡通化。
```

```text
使用 pet-streetwear-mood-avatar，把我的鸟做成小绅士。
戴为冠羽留孔的老爷帽、穿合身小西装，置于精致的木饰面客厅；
红酒杯只放在旁边小茶几上，鸟不要拿杯子。
```

## 输出规则

- 从构图开始就是 1:1，不能先生成竖图或横图再裁切。
- 每张图只讲一个主行为，配 1 件主动作物与 1–2 件合理的小物。
- 服装必须顺着宠物的真实肩背、胸口、前肢、翅膀或颈部自然穿戴。
- 不输出可读文字、品牌 Logo、水印、日期、标签或伪文字。
- 场景可以变化，但始终保留复古美式直闪的色彩关系与真实生活感。
