# 宠物潮流头像场景库

用于需要换场景、活动或穿搭方向时。每条都保持：宠物身体做人的动作、1 件主动作物、1–2 件关联小物、无品牌无文字，以及美式复古直闪色彩关系。场景是起点，不是强制复刻；优先响应用户给出的宠物性格、服装和地点。

## 使用约束

- 一张图只选择一个场景，不把不同表格中的道具拼成“主题派对”。
- 场景变化必须伴随姿势与道具变化；只换衣服不算新场景。
- 同一批头像避免连续使用同一沙发、同一木墙、同一遥控器或同一正面半躺构图。
- 复古硬闪、明确色彩角色、宠物身份和自然肢体结构始终不变。
